To Picture — портативная версия.

Пока этот файл лежит рядом с "To Picture.exe", программа работает в портативном режиме:
настройки и служебные файлы хранятся в папке "data" рядом с программой, в системе
(AppData, реестр) ничего не остаётся. Папку можно переносить на флешку или другой компьютер.

yt-dlp и ffmpeg лежат в папке "bin". yt-dlp обновляется сам раз в сутки — для этого папка
должна быть доступна для записи.

Нужен Windows 10/11 x64 с Microsoft WebView2 (в Windows 11 он уже есть; для Windows 10:
https://developer.microsoft.com/microsoft-edge/webview2/).

Удаление — просто удалить папку.
